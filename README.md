## About Me

I am a Full Stack MERN Developer based in Pakistan, focused on building scalable, secure, and production-ready web applications. My core strength lies in React.js, where I design component architectures that are reusable, maintainable, and built to scale with a product rather than against it.

On the backend, I work with Node.js, Express.js, and MongoDB to build RESTful APIs that are structured, well-documented, and ready for real traffic. I pay close attention to clean architecture — separating concerns properly, keeping business logic testable, and writing code that the next developer can actually understand.

My development philosophy is simple: interfaces should feel fast and intentional, code should be readable before it is clever, and every application I ship should be something I would be comfortable maintaining a year from now. I care about performance optimization, responsive design across devices, and modern UI/UX that puts the user experience first without sacrificing engineering quality underneath.

Currently, I am deepening my expertise in advanced React patterns and backend system design, while contributing to and building open-source tooling that other developers can rely on.

## Automation

This profile keeps itself current using scheduled GitHub Actions workflows:

| Workflow | Purpose | Schedule |
|---|---|---|
| `snake.yml` | Generates the contribution snake animation | Daily |
| `metrics.yml` | Refreshes GitHub metrics and stats snapshot | Daily |
| `update-readme.yml` | Keeps dynamic sections in sync | Every 12 hours |

<details>
<summary><b>Snake Animation Workflow</b></summary>

```yaml
name: Generate Snake Animation

on:
  schedule:
    - cron: "0 0 * * *"
  workflow_dispatch:
  push:
    branches:
      - main

jobs:
  generate:
    permissions:
      contents: write
    runs-on: ubuntu-latest
    steps:
      - name: Generate contribution snake
        uses: Platane/snk@v3
        with:
          github_user_name: iLhamAmjad01
          outputs: |
            dist/github-contribution-grid-snake.svg
            dist/github-contribution-grid-snake-dark.svg?palette=github-dark

      - name: Push output to output branch
        uses: crazy-max/ghaction-github-pages@v4
        with:
          target_branch: output
          build_dir: dist
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

</details>

<details>
<summary><b>GitHub Metrics Workflow</b></summary>

```yaml
name: Update Metrics

on:
  schedule:
    - cron: "0 6 * * *"
  workflow_dispatch:

jobs:
  update-metrics:
    runs-on: ubuntu-latest
    permissions:
      contents: write
    steps:
      - uses: lowlighter/metrics@latest
        with:
          token: ${{ secrets.METRICS_TOKEN }}
          user: iLhamAmjad01
          template: classic
          base: header, activity, community, repositories, metadata
          plugin_languages: yes
          plugin_lines: yes
          plugin_stars: yes
```

</details>

<details>
<summary><b>Automatic README Update Workflow</b></summary>

```yaml
name: Auto Update README

on:
  schedule:
    - cron: "0 */12 * * *"
  workflow_dispatch:

jobs:
  update-readme:
    runs-on: ubuntu-latest
    permissions:
      contents: write
    steps:
      - uses: actions/checkout@v4
      - name: Update dynamic content
        run: echo "Sync step for dynamic README sections"
      - name: Commit changes
        run: |
          git config --local user.email "action@github.com"
          git config --local user.name "GitHub Action"
          git add README.md
          git diff --quiet && git diff --staged --quiet || git commit -m "Auto update README"
          git push
```

</details>
